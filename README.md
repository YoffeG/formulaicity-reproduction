# An Unsupervised Information-Theoretic Approach to Identifying Formulaic Clusters in Textual Data

This repository provides the software, data, and reproducibility materials
associated with the article *An Unsupervised Information-Theoretic Approach
to Identifying Formulaic Clusters in Textual Data*. The supplied programs
generate Figures 1--6 and preserve the numerical results underlying each
figure in machine-readable formats.

## Installation

Python 3.13.7 and the versions recorded in `requirements-lock.txt` constitute
the tested environment.

```bash
git clone https://github.com/YoffeG/formulaicity-reproduction.git
cd formulaicity-reproduction
python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-lock.txt
```

For exploratory environments that do not require exact package versions,
install the compatible version ranges in `requirements.txt`.

All commands below are intended to be run from the repository root.

## Data

Figures 1 and 2 use synthetic data generated by their respective programs.
Figures 3--6 use the following files in `data/`:

- `Genesis_Lists_Narrative.csv`
- `Exodus_P-nonP_Roemer_AB.csv`
- `Leviticus _PH_14-3-2022.csv`
- `TOTHT_corpus_full`

The CSV files contain the expert annotations used for evaluation. The
`TOTHT_corpus_full` file contains the corresponding tokenized biblical corpus.
File descriptions and SHA-256 checksums are provided in `data/README.md`.

## Figure 1: categorical benchmark

`figure1.py` generates the nine-panel benchmark for binary categorical data.
For every simulated dataset, the information-theoretic method, k-means, GMM,
and DBSCAN are evaluated on the same binary feature matrix. The curves report
the mean normalized MCC, and the shaded regions report one population standard
deviation across simulations.

The information-theoretic calculation follows Equations 7--10 of the article:

```text
p_j(s) = sum_i(s_i x_ij) / sum_i(s_i)
L(s) = -sum_i [s_i log P(x_i|s) + (1-s_i) log P(x_i|1-s)]
```

Run the complete benchmark:

```bash
python figure1.py \
  --simulations 100 \
  --workers 12
```

Outputs are written to `output/figure_1/`:

- `figure_1.pdf`
- `figure_1.png`
- `figure_1_trials.csv`
- `figure_1_summary.csv`
- `figure_1_metadata.json`

Interrupted computations resume from `figure_1_trials.csv`. To redraw the
figure from existing results:

```bash
python figure1.py \
  --simulations 100 \
  --plot-only
```

The implementation of the loss and analytic gradient can be checked directly:

```bash
python audit_figure1_math.py
```

## Figure 2: multivariate Gaussian benchmark

`figure2.py` generates the six-panel benchmark for multivariate Gaussian data.
It compares Self-Information, the $L_2$ norm, Gaussian Mixture, regularized
EM, and CEC across the dimensions, sample sizes, and noise levels specified in
the article. The Gaussian objective is evaluated with continuous membership
weights, analytic derivatives, and bounded L-BFGS-B optimization. The weighted
covariance follows Equation 19, and the two Gaussian covariance spectra use
eigenvalues 10 and 30. Shaded regions show one population standard deviation
across the simulations.

Run the standard 100-simulation analysis:

```bash
python figure2.py \
  --simulations 100 \
  --workers 12
```

For a higher-precision estimate, increase the number of simulations:

```bash
python figure2.py \
  --simulations 1000 \
  --workers 12
```

The Differential Entropy comparator is optional and can be included with
`--include-differential-entropy`.

Outputs are written to `output/figure_2/` and include the PDF, PNG, trial CSV,
summary CSV, and metadata JSON. Interrupted computations resume from the trial
CSV. To redraw the figure without repeating the simulations:

```bash
python figure2.py \
  --plot-only
```

The weighted mean and covariance implementation can be checked directly
against Equation 19:

```bash
python audit_figure2_math.py
```

## Figures 3--5: biblical text analyses

`figures3_5.py` performs the parameter sweeps for Genesis, Exodus, and
Leviticus. Each textual segment is represented by an n-gram count vector. The
information-theoretic analysis estimates cluster-specific Multinomial feature
distributions from these counts, while k-means is evaluated on the same count
matrix.

Run all three books:

```bash
python figures3_5.py \
  --book all \
  --jobs 3
```

The parameter grid contains 260 configurations per book:

- n-gram size: `n = 1, 2, 3, 4, 5`
- running-window width:
  `ell = 2, 3, 4, 6, 8, 10, 12, 14, 18, 22, 24, 26, 28`
- number of features: `f = 100, 300, 500, all`

Use `--book genesis`, `--book exodus`, or `--book leviticus` to analyze one
book. Each completed configuration is written immediately to the checkpoint
CSV, and an interrupted parameter sweep resumes automatically.

A limited pipeline test can be run with:

```bash
python figures3_5.py \
  --book genesis \
  --limit-combinations 1 \
  --optimizer-restarts 1 \
  --optimizer-iterations 5
```

Completed results can be replotted without repeating the parameter sweep:

```bash
python figures3_5.py \
  --book all \
  --plot-only
```

Outputs are written to `output/figures_3_5/`. The principal PDFs are:

- `genesis_gen_results_new.pdf`
- `Exodus_results_new.pdf`
- `leviticus_results_new.pdf`

The `--score-model binary` and `--score-model binomial` options are available
for comparative analyses; the default textual analysis uses the Multinomial
model.

## Figure 6: Leviticus feature analysis

`figure6.py` generates the two Leviticus panels and combines them into one
figure. The main axes display normalized feature importance with uncertainty
estimated from repeated half-samples. Each inset displays the empirical
leave-one-out self-information distributions of the two fitted clusters.

The two configurations are:

- panel (a): `ell = 12`, `n = 3`, `f = 500`
- panel (b): `ell = 6`, `n = 5`, `f = 500`

The fitted cluster with the lower mean leave-one-out self-information is
identified as the formulaic cluster. Blue represents the non-formulaic
cluster, and orange represents the formulaic cluster. The inset significance
annotation reports the absolute difference between the cluster means relative
to its randomization-null standard deviation.

Run the analysis:

```bash
python figure6.py \
  --jobs 2
```

Outputs are written to `output/figure_6/`:

- `figure_6.pdf`
- `figure_6.png`
- one PDF and PNG for each panel
- one feature table and metrics JSON file for each panel
- `figure_6_metadata.json`

To combine existing panel PDFs without repeating the analysis:

```bash
python figure6.py \
  --combine-only
```

## Validation

Reference numerical results are stored in `expected/`. After generating
Figures 1, 2, and 6, run:

```bash
python validate_reproduction.py
```

The validator checks the installed package versions, verifies the Figure 1
loss and gradient and the Figure 2 weighted covariance, and compares the
generated numerical summaries with the reference results. Numerical outputs
are compared directly; PDF and PNG files are not byte-compared because font
rendering and embedded metadata may vary across operating systems.

## Software organization

The four user-facing programs are:

- `figure1.py`
- `figure2.py`
- `figures3_5.py`
- `figure6.py`

Supporting modules are organized by function:

- `figure2_engine.py`: simulation and plotting for Figure 2
- `figure2_methods.py`: Figure 2 data generation and comparison methods
- `figures3_5_engine.py`: parameter sweeps and plotting for Figures 3--5
- `figure6_panel.py`: analysis and plotting of an individual Figure 6 panel
- `formulaicity_optimization.py`: shared optimization and cluster-orientation
  routines
